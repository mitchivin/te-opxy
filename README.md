# OP-XY | Interactive Study

An interactive browser version of the Teenage Engineering OP-XY. Play its keys and controls, explore the device in 3D, and build or play featured tracks.

**[Open OP-XY](https://mitchivin.github.io/te-opxy/) · [Explore OP-1 Field](https://mitchivin.github.io/te-op1-field/)**

Free to use. Works on desktop and phone.

![OP-XY interactive 3D device](preview.jpg)

## Features

- **Playable device.** Keys, buttons and encoders respond, with a live device display.
- **Sequencer and sounds.** Build patterns and shape sounds. Your project stays saved in your browser.
- **Featured tracks.** Blinding Lights, Children, The Final Countdown, Project Lee, Sandstorm and Sweet Dreams.
- **Two ways to play a track.** Choose the wrench icon (**Watch build**) to see the track built step by step, or the musical-note icon (**Full song**) to hear it straight through.
- **Camera views.** Move between the screen, the controls and the hardware details.

![OP-XY screen and controls](surface.jpg)

## Keyboard

| Key | Action |
| --- | --- |
| Letter and number keys | Play notes |
| Space | Play or stop |
| Esc | Stop |
| P | Power |
| R | Record |
| M | Metronome |
| [ ] | Pitch bend |
| Alt + 1 to 9 | Choose a song |
| I | Hide the on-screen controls (desktop) |

## Get started

1. Open [OP-XY](https://mitchivin.github.io/te-opxy/).
2. Choose a song. Choosing a song starts it.
3. Use the transport to stop, pause or resume, or play the keys yourself.

This is a browser interpretation with simulated sound and workflows. It is not official firmware or a complete hardware emulator.

This repository hosts the compiled website and public project information. The application source is not published here.
